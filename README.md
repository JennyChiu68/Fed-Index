# Fed Pulse · 官方数据研究版

手机优先、单页面的美联储沟通指数与委员观察工具。公开站点：https://fed-pulse-demo.kinardqgumt.chatgpt.site

## 技术交接

完整前端、服务端、数据采集器、数据快照、数据库迁移和测试都包含在本仓库。

- [功能需求 Word 文档](docs/美联储鹰鸽指数功能需求.docx)：2026 年 10 月 16 日的上线需求，声明、会议纪要和官员讲话统一使用金十数据授权快讯 API，并规定 AI 评分和摘要提示词、后台更新频次、官员名单动态维护及事件去重规则。
- [当前手机页面预览](docs/preview-mobile.jpg)。

**当前代码实现与上线需求分开说明：** 当前可运行 Demo 已实现下文描述的官方公开资料采集、规则评分、原文绑定的语义复核和 CME FedWatch 六次会议概率；金十 API、AI 评分与摘要、持续后台扫描，以及完整的人员任期动态机制尚未在当前代码中接入。需求文档是这些上线工作的实施依据，仓库没有包含任何个人 API 密钥。

## 已接入的数据

- 美联储理事会及 12 家地区联储的官方讲话目录、政策文本和官方摘要；每条记录保存 URL、源站公布日期、采集时间和评分依据。
- FOMC 官网的当年 12 位投票成员名单，以及当前 19 位政策参与者观察名单。
- 纽约联储官方 EFFR API：有效联邦基金利率、目标区间、有效日期。
- FOMC 官方跨年会议日历、最新政策声明和已发布会议纪要；政策要点绑定核对过的原文，源文变更后不沿用旧中文摘要。

CME 市场概率读取用户指定 CME FedWatch 官网内嵌 QuikStrike 的免费 Current 表。Current 数据时间异常时，改取表内具有明确历史日期的最近有效列，页面明确标记历史日期。历史列的加息、维持与降息汇总按源表舍入后的分布归一化，逐档概率保留原值。提供未来六次 FOMC 会议日期切换，显示各次会议后的目标利率分布及相对当前区间的累计概率，注明 CME FedWatch 与源站数据时间。未使用付费 API，也不把期货隐含概率并入官方文本指数。

采集器按公开工具的普通会话与跳转流程取数，每次访问最多每 5 分钟重新检查，使用独立 D1 缓存。每次通过 CME 正常日期控件顺序读取六张 Current 表，保留各表自己的数据时间；单个日期失败时保留该日期缓存，缺失时显示未取得，不借用其他日期的概率。默认最近一次会议，切换及刷新保留用户选中的日期。远期概率反映截至该会议的累计利率预期，不代表那一次会议独立加息或降息的概率。校验会议日期、当前目标区间、Now 列、概率总和与原始 CT 时间；CT 按 America/Chicago 的夏令时转换。请求失败保留上次有效数据并标注，已过期或与官方下一次会议不符的表不展示。源站时间较早时保留原时间，不伪装成实时更新；无访问时不会采集。

本地重采集：`node scripts/collect-fedwatch.mjs`。解析与会话流程验证：`node --test tests/fedwatch.test.mjs`。

## 指数口径

这是本产品从真实官方文本计算的 **规则研究指数**，不是美联储或第三方已发布的指数。固定 0–100 量表，50 中性；45–55 为中性观察区间。算法未完成独立校准或预测能力回测。

当前版本为 `official-text-semantic-1.4`。已核对的发言使用 URL、作者、活动日期和完整正文绑定的语义复核记录；任何一项变化都使原复核失效，转为明确标记的自动规则结果。新文本仍需后续技术实现持续 AI 处理。规则排除可辨认的历史投票、集体预测和假设教学案例，同义复述不重复，每类最多两条独立证据，条件主张减半。单篇原始分 r=(鹰向强度−鸽向强度)/(两者强度之和+3)，展示分为 round(50×(1+r))。

先按人聚合近90日文本，使用30日时间常数；再按主席2、理事会副主席及纽约联储主席1.5、监管副主席及其他1加权，票委再乘1.25。时间权重只影响同一人各篇文本的相对比重，不把单篇旧观点自动拉回中性。计算日期按北京时间切日，活动日期保留官方日期。

综合分至少覆盖在任观察名单的一半（向上取整），不足时保留空值；个人分数和覆盖人数仍可查看。没有证据不补50分。明确维持或没有给出方向的政策内容标为 `policy_no_direction`；活动预告、文字稿不足、来源失败与数值零分别处理。

历史是按当前观察名单、当前规则和已收录资料回算，不能替代当时实盘发布档案。日期列表、CSV和每日归因都保留回算说明。每天可以打开对应的新增发言和计算调整；缺少有效基准时不编造变化值。

最新一批发言按日期与来源链接固定顺序逐篇加入重算，展示可相加的回算贡献；时间、样本到期和取整差额单列。相同正文只按一个来源事件计入。本 Demo 没有声称掌握原始快讯的完整到达次序、补充及修订历史，生产事件流水仍按需求文档实施。

## 数据服务与更新

应用由 Sites 官方 Vinext/Cloudflare Worker 运行，D1 保存最近核实数据与按日观察缓存，尚不是逐次不可覆盖的发布流水。`GET /api/pulse` 读取缓存并触发过期数据的后台刷新；`GET /api/pulse?wait=1` 可等待完成，仍有5分钟刷新间隔；`GET /api/pulse?history_date=YYYY-MM-DD` 读取近90天内指定日的回算及归因，不触发市场数据抓取。源站暂时不可用时保留已核实内容及原始日期，标明数据陈旧或来源失败；委员名单未通过官方核验时不接受新的指数更新。

页面加载、重新可见和每 5 分钟请求一次。仅访问驱动刷新不等于关闭页面后的持续扫描；后台安排若已启用，以 Sites 关联自动化为准。

## 开发

需要 Node.js 22.13.0 或以上版本。首次获取代码后执行：

```sh
git clone https://github.com/JennyChiu68/Fed-Index.git
cd Fed-Index
npm run install:ci
npm run dev
```

检查与构建：

```sh
npm run check
node --test tests/*.test.mjs
node scripts/verify-data.mjs
npm run build
npm run start
```

本地资料采集（需要网络与 curl）：`node scripts/collect-official.mjs`。初始真实资料在 `data/verified-source-data.json`，质量检查结果在 `data/quality-report.json`。生产不会读取本地 curl，它使用 Worker 内置 fetch。

D1 迁移在 drizzle/，生产发布由 Sites 应用。发布继续使用已有 Site 身份及公开访问设置。

`.openai/hosting.json` 保存现有 Site 身份和绑定名称，属于构建配置。将代码迁移到独立 Cloudflare 账号时，需要自行创建 D1 数据库、执行 `drizzle/0000_chief_matthew_murdock.sql`，并将 Worker 的 `DB` 绑定到该数据库；仓库中的占位数据库 ID 不能直接当成生产数据库使用。GitHub 推送本身不会替代站点发布，也不会同步运行中的 D1 缓存；初始化数据使用仓库内的公开快照。

## 当前范围与限制

观察名单当前为 19 人；近期可评分文本覆盖以 API 和页面为准。官方目录可能漏掉临时媒体采访，部分地区联储只提供视频，部分 HTML 正文包含源站摘要；展示为官方文本摘录，不冒称逐字讲话引述。FOMC票委姓名与配置中的人员匹配，核验字段不再把所有19人标为当次身份核实。跨年时仅在已核实的新年首次会议之前接受上一年度票委标题；未知投票成员或投票页结构变化仍触发核验失败；非票委人员更替需要维护观察名单配置。完整任职生效期、代理关系及自动名单维护属于后续生产工作。

每个来源的请求状态、更新时间和原文链接可从页面信息按钮查看。官方网页的发布时间与抓取时间分别记录，不用抓取时间伪装讲话的有效时间。

## 委员证据覆盖

个人文本评分继续使用 90 日窗口，不用投票事实填补个人鹰鸽分数。页面“委员证据覆盖”按有效个人文本或最新 FOMC 实名投票计数，同一人只计一次；点击可查看个人文本、投票委员文本和实名投票的分开统计。缺少个人文本时仍保留空分数，显示该次决议的实名投票及会议纪要原文。集体决议单独展示，不能据此推定委员支持后续相同方向的调整。

采集扩展到克利夫兰联储首页和旧金山联储活动实录。带发言人标签的戴利对话只保留其本人段落；主持人和其他嘉宾不参与评分。官方会议纪要的投票仅关联同日决议，并核验完整的 12 人投票名单。

## Demo交互

委员区域以五档人数分布和两列卡片展示，支持阵营、票委筛选、展开名单、查看最近发言及较早资料标记。决议详情分开展示本次声明和最新已发布纪要的日期、要点和官方原文。方法弹层说明覆盖门槛、量表、权重及回算口径。评论为本机留言，订阅为本机偏好，均不向外发送内容或冒充消息推送服务；“问AI”复制当前结构化资料和提示词。
