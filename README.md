# Fed Pulse · 官方数据研究版

手机优先、单页面的美联储沟通指数与委员观察工具。公开站点：https://fed-pulse-demo.kinardqgumt.chatgpt.site

## 已接入的数据

- 美联储理事会及 12 家地区联储的官方讲话目录、政策文本和官方摘要；每条记录保存 URL、源站公布日期、采集时间和评分依据。
- FOMC 官网的当年 12 位投票成员名单，以及当前 19 位政策参与者观察名单。
- 纽约联储官方 EFFR API：有效联邦基金利率、目标区间、有效日期。
- FOMC 官方会议日历与最新政策声明。

CME 市场概率目前没有接入：官方生产 API 需要订阅。站点保留官方 FedWatch 外链，已删除所有模拟概率与模拟讲话。

## 指数口径

这是本产品从真实官方文本计算的 **规则研究指数**，不是美联储或第三方已发布的指数。固定 0–100 量表，50 中性；45–55 为中性观察区间。算法未完成独立校准或预测能力回测。

规则识别当前收紧/宽松偏好、通胀与就业风险；同一规则每篇最多两次，条件语气减半，明显假设示例和过去年份叙述不参与。单篇分数 s=(鹰向权重−鸽向权重)/(总权重+3)，再先按人聚合，采用 90 日窗口、30 日时间常数；角色与当年投票权用于委员间加权。

缺少证据不补中性。无可评分文本、视频未提供文字稿、源站失败或结构变化均保留缺失状态。页面明确显示样本覆盖，不能把已覆盖样本的指数当作所有未覆盖者的观点。

历史曲线是以当前委员名单和当前模型，根据已收集原文回算的事件序列，不是当时发布的实盘指数。无事件时沿用上一有效事件值，不插值制造政策变化。CSV 同样带模型版本、覆盖人数与回算标记。

单篇边际影响采用移除该篇后的重算差，彼此不可简单相加；时间权重、样本变动、非线性与取整残差单独保留。

## 数据服务与更新

应用由 Sites 官方 Vinext/Cloudflare Worker 运行，D1 保存最近核实数据与实际观察记录。`GET /api/pulse` 读取缓存并触发过期数据的后台刷新；`GET /api/pulse?wait=1` 可等待完成，仍有 5 分钟刷新间隔。源站暂时不可用时保留已核实内容及原始日期，标明数据陈旧或来源失败；委员名单未通过官方核验时不接受新的指数更新。

页面加载、重新可见和每 5 分钟请求一次。仅访问驱动刷新不等于关闭页面后的持续扫描；后台安排若已启用，以 Sites 关联自动化为准。

## 开发

```sh
npm run dev
npm run check
node scripts/verify-data.mjs
npm run build
npm run start
```

本地资料采集（需要网络与 curl）：`node scripts/collect-official.mjs`。初始真实资料在 `data/verified-source-data.json`，质量检查结果在 `data/quality-report.json`。生产不会读取本地 curl，它使用 Worker 内置 fetch。

D1 迁移在 drizzle/，生产发布由 Sites 应用。发布继续使用已有 Site 身份及公开访问设置。

## 当前范围与限制

观察名单当前为 19 人；近期可评分文本覆盖以 API 和页面为准。官方目录可能漏掉临时媒体采访，部分地区联储只提供视频，部分 HTML 正文包含源站摘要；展示为官方文本摘录，不冒称逐字讲话引述。身份轮换或官网结构改变会触发验证失败，适配器需要维护。

每个来源的请求状态、更新时间和原文链接可从页面信息按钮查看。官方网页的发布时间与抓取时间分别记录，不用抓取时间伪装讲话的有效时间。
