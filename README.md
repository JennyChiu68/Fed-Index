# Fed Pulse

手机优先的美联储鹰鸽指数产品 demo。采用原生 HTML、CSS、JavaScript，无需依赖安装。

## 运行

在本目录执行 `npm run dev`，访问 http://127.0.0.1:5173。检查脚本语法：`npm run check`。

## 产品选择

主指数为 0–100 的政策沟通量表，50 固定为中性。借鉴 FXStreet 的聚合事件更新和 RoboMacro 的公开计算方式；单独展示会议市场概率。拟定 v1 方法：先按委员聚合讲话，再按角色与投票权加权，避免高频发言人的样本数量主导指数。完整方法、来源和正式产品接入步骤见 app 内「方法」。参数尚需历史校准。

## 演示范围

- 390px 手机优先，兼容 320px 至桌面窗口。
- 指数、信号、委员、方法四个页面。
- 偏鹰、偏鸽、中性、静默四种场景。
- 7/30/90 天走势，历史读数弹窗、触摸查看、CSV 导出。
- 信号筛选与归因详情、委员投票筛选、会议概率切换。
- 静默场景保留有效更新时间及指数，独立展示模拟市场概率。

**所有数字、历史、委员、概率、讲话及归因都是合成演示数据。没有实时 API、后端、官方模型或经过回测的投资信号。** 委员分布是独立的界面展示样本，不由这六人计算主指数。`dist/data.js` 集中管理模拟数据；生产接入须替换数据适配层。

## 核查要点（2026-10-12）

FXStreet 已有 100 为中性的事件更新指数；RoboMacro 公布时间与角色权重；Fed Chirp 在工作日晚扫描，但会议分数与扫描日期不能混为一谈；MacroMicro 主要分析 FOMC 声明；Bloomberg 有 NLP 研究指数。J.P. Morgan 也有 Hawk-Dove Score，PIMCO 2025 年 10 月公开报告的披露部分予以确认；未核实免费实时公众入口。

来源链接在 app「方法」页内，最新数值未采用于 demo。公开产品不能直接提供本产品所需的全部可授权原始数据。正式产品应自行采集官方政策文本，并选择有授权的期货或概率数据接口。
